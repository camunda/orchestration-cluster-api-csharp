ActivateProbesAsync(ProbeActivationRequest, CancellationToken)

Activate probes (alpha) Collects probes of the given probe IDs for a worker, up to the requested maximum.

Like job activation, the request goes to every partition. When no probe is waiting, it is held until a probe of one of these probe IDs is created or until requestTimeout. Probe IDs on which the caller lacks the ANSWER permission are skipped. The worker answers each probe with POST /v2/probes/{probeKey}/answer before the probe's deadline.

This endpoint is an alpha feature and may be subject to change in future releases.

Examples

public static async Task ActivateProbesExample(ProbeId probeId)
{
    using var client = CamundaClient.Create();

    var result = await client.ActivateProbesAsync(new ProbeActivationRequest
    {
        ProbeIds = new List<ProbeId> { probeId },
        Worker = "health-check-worker",
        MaxProbesToActivate = 10,
        RequestTimeout = 30000,
    });

    foreach (var probe in result.Probes)
    {
        Console.WriteLine(
            $"Probe {probe.ProbeKey} ({probe.ProbeId}) must be answered by {probe.Deadline}");
    }
}

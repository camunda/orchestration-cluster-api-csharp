Content

The content blocks of this history item.

HistoryItemId

Caller-assigned identifier used to detect and dedupe retries of the same item. For example, when a retried job activation resubmits history items it already sent in an earlier attempt, those items are not rejected; they are flagged via isDuplicate in the response instead. Must be non-blank.

Limits

The operational limits as of this entry. CONFIGURATION items only; omit for other roles.

LoopIteration

The loop iteration this item belongs to.

Metrics

Per-call token and latency metrics. Present on ASSISTANT items only.

Model

The LLM model identifier as of this entry. CONFIGURATION items only; omit for other roles.

ProducedAt

The agent-side timestamp of when this message was produced.

Provider

The LLM provider as of this entry. CONFIGURATION items only; omit for other roles.

Role

The role of this history item in the conversation.

SystemPrompt

The system prompt, as content blocks, as of this entry. CONFIGURATION items only; omit for other roles. Omit to leave the system prompt unchanged; when present, must be non-empty.

ToolCalls

Tool calls associated with this history item. For ASSISTANT items: tool calls dispatched by this LLM response. For TOOL_RESULT items: single-entry array referencing the originating tool call. Omit for USER items.

Tools

The complete list of tools available to the agent as of this entry. CONFIGURATION items only; omit for other roles. Omit to leave the tool list unchanged; send an empty array to clear it.

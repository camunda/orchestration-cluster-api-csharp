; Ambient wall-clock and timer primitives, banned in the SDK runtime by the cross-SDK
; injected-clock contract (camunda/orchestration-cluster-api-js#450).
;
; Resolve time through the injected TimeProvider instead: the client's clock is on
; CamundaClient (_timeProvider) and is handed to handlers as ActivatedJob.Clock.
;
; This file applies to the SDK project only. Test projects legitimately use ambient
; time and do not reference the analyzer.
;
; Two exemption categories exist, both applied narrowly with #pragma or a path-scoped
; .editorconfig entry rather than by widening this list:
;   - the live clock itself (CamundaTimeProvider), which is the one allowed place the
;     system clock is read;
;   - liveness bounds, i.e. timers whose job is to stop something waiting forever. On a
;     pinned clock those would never fire, so shutdown drains and network timeouts stay
;     on real time.
